
# M. RAJ ELECTRIC

Welcome to the official website project of **M. RAJ ELECTRIC**, an electrical store located in Morbi, Gujarat.

## About the Store

M. RAJ ELECTRIC provides electrical products and everyday electrical essentials, including:

- LED Lights and Decorative Lights
- Ceiling Fans
- Wires and Cables
- Switches and Sockets
- Electrical Appliances
- Room Heaters and Irons
- Induction Cooktops
- Other Electrical Accessories

## Website Features

- Browse products by category
- View product details and prices
- Add products to the shopping cart
- Update product quantities
- Place orders online
- UPI and Cash on Delivery payment options
- Delivery availability in Morbi and Rajkot
- WhatsApp order enquiries

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages
- EmailJS
